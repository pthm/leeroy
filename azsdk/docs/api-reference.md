# API reference

Generated by `cmd/apigen` from the function registry and package `types`: don't edit by hand.
Conventions are in sdk.md. `request<T>`: an action's request, whose result's `data` is a `T` when it's ok. `T?`: nil with the availability meaning documented by that function. Item selectors are a positive numeric template entry or a decimal instance GUID string (never a numeric GUID or a quoted entry).
