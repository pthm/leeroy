# API reference

Generated by `cmd/apigen` from the function registry and package `types`: don't edit by hand.
Conventions are in sdk.md. `request<T>`: an action's request, whose result's `data` is a `T` when it's ok. `T?`: nil when unknown (out of sight, not loaded yet, none).
